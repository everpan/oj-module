## 二、文档权威性

- **4 篇读者文档为当前权威面**，日常以它们为准。
- `archive/` 中 21 篇为**历史真源**（PRD、设计 v3、契约 v1.3、RBAC 设计、各期执行计划、教学实录、上游 PR 稿等），保留用于追溯决策编号（D1–D14 / R1–R31 / P0–P4 / OJ-1~9）与原文细节。
- 真源优先级（用于收口历史冲突）：设计 v3 > 契约 v1.3 > RBAC 设计 > PRD > 早期 registration-design。
- 各篇文末均设「已知限制与待确认」专节，列出**需人工拍板的真源矛盾**（如 OJ-8 状态表述不一、主计划 §7 阶段小结滞后），未做静默篡改。
