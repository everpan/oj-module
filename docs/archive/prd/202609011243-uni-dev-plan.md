> 步骤用 `- [ ]` 勾选跟踪；每阶段完成后更新本文勾选 + 任务状态 + 阶段小结。

**Goal:** ram 四命令（init/dev/build/preview）完成前后端一体化工程全生命周期，oj 为被编排的实现细节。

**Architecture:** ram 编排器 + oj 子进程（dev 反代 /api、preview 先 migrate 后 server + ram 静态兜底）；runtime api 层单向适配 oj 原生契约（D10）；布局探测收敛单一模块（D11 迁移 + 删除里程碑）。

**Tech Stack:** TypeScript + node:http/child_process/crypto（零新运行时依赖）、vitest、tsx、vite/esbuild（既有）。

## Global Constraints

- 代码风格：Tabs、双引号、分号（eslint @antfu，pre-commit 自动跑）
- 提交：conventional commits（commitlint 把守）
- **禁止新增 npm 运行时依赖**（反代/tar/JWS 全用 node:stdlib；tar 用系统 `tar`）
- TDD：每个任务先写失败测试（红）→ 最小实现（绿）→ 重构 → 提交
- 测试放 `tests/cli/`（cli 域）、`tests/runtime/`（runtime 域）、`tests/e2e/`（冒烟，CI 跳过）；跑法 `pnpm test`（根 vitest）
- vendor 二进制仅 macOS（init 检 `process.platform === "darwin"`，否则人话报错）
- 全部 oj 子进程命令行参数用绝对路径；`-b /api` 钉前缀
- SOLID：布局探测、证书签发、oj 进程编排、静态服务各收敛单一文件；`scripts/build-modules.ts` 依赖的 `readModuleDefinition` 导出签名不得变更

```ts
// packages/cli/src/oj-cert.ts —— D6：per-project 现场签发，私钥不随包分发
import crypto from "node:crypto";
import fs from "node:fs";
import path from "node:path";

const b64url = (input: Buffer | string) =>
	Buffer.from(input).toString("base64url");

export async function mintDevCert(outDir: string, opts: { days?: number } = {}) {
	const days = opts.days ?? 3650;
	const { privateKey, publicKey } = crypto.generateKeyPairSync("rsa", { modulusLength: 2048 });
	const now = Math.floor(Date.now() / 1000);
	const header = b64url(JSON.stringify({ alg: "RS256" }));
	const payload = b64url(JSON.stringify({ nbf: now, exp: now + days * 86400 }));
	const signingInput = `${header}.${payload}`;
	const signer = crypto.createSign("RSA-SHA256").update(signingInput);
	const signature = b64url(signer.sign(privateKey));
	fs.mkdirSync(outDir, { recursive: true });
	const write = (name: string, data: string) => {
		const file = path.join(outDir, name);
		fs.writeFileSync(file, data);
		return file;
	};
	const privateKeyPath = write("private.pem", privateKey.export({ type: "pkcs8", format: "pem" }).toString());
	const publicKeyPath = write("public.pem", publicKey.export({ type: "spki", format: "pem" }).toString());
	const certPath = write("cert.jws", `${signingInput}.${signature}\n`);
	return { privateKey: privateKeyPath, publicKey: publicKeyPath, cert: certPath };
}
```
